- Use create-next-app with latest version
- Enable TypeScript
- Enable Tailwind CSS
- Use App Router (not pages router)
- Add ESLint
- Use pnpm as package manager

Production dependencies:
- prisma
- @prisma/client
- next-auth
- bcryptjs
- zod
- react-hook-form
- @hookform/resolvers

Dev dependencies:
- @types/bcryptjs
- tsx
